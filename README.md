# Goba Hospital Patient Record Management System

A comprehensive web-based patient record management system for Goba Hospital that allows doctors, patients, staff, and administrators to manage medical records efficiently.

## Features

### User Portals
- **Patient Portal**: View medical history, search records, manage profile
- **Doctor Portal**: Record consultations, surgeries, diagnoses, search patient history
- **Staff Portal**: Record medicine dosages, manage patient information
- **Admin Portal**: Manage users, hospitals, system administration
- **External Health Office Portal**: Upload and send patient information

### Key Functionalities
- Patient registration with National ID/Passport/Birth Certificate
- Medical record management (consultations, surgeries, diagnoses)
- Audio recording for consultations
- Payment processing with multiple banks
- File upload capabilities (PDF, JPG)
- Advanced search functionality
- Responsive design for all devices

## Technology Stack
- **Frontend**: HTML5, CSS3, JavaScript, jQuery
- **Backend**: PHP
- **Database**: MySQL
- **Additional**: Bootstrap for responsive design

## Installation
1. Clone the repository
2. Set up a web server with PHP and MySQL
3. Import the database schema
4. Configure database connection
5. Access the system through your web browser

## Database Schema
The system includes tables for patients, doctors, staff, hospitals, consultations, operations, diagnoses, and medical administration records.

## Security Features
- Secure login system
- Role-based access control
- Data encryption for sensitive information
- Session management
